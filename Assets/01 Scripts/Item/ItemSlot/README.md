# ItemSlot

> 아이템을 담는 슬롯을 관리하는 클래스를 모아둔 폴더입니다.

## ItemSlot

현재 슬롯에 들어있는 아이템과 아이템의 개수를 관리하며 아이템 추가, 감소, 분할, 사용, 삭제의 메서드가 구현되어 있습니다. 


## EquipSlot

총기를 장착할 수 있는 아이템 슬롯 클래스입니다. ItemSlot를 상속받습니다. 

HUD에 EquipUI와 연동됩니다. 

## QuickSlot

플레이어가 아이템을 빠르게 사용할 수 있는 퀵슬롯을 관리하는 클래스입니다. 


### 주요 기능 

- HUD에 QuickSlotUI과 연동 

- InputSystem 설정 

- Inventory Slot UI와 연결 및 상호작용 관리
