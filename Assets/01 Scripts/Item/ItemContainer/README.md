# ItemContainer 
> 여러 아이템 슬롯을 가진 아이템 컨테이너 클래스를 모아둔 폴더입니다. 

## Inventory

플레이어의 아이템, 재화를 관리하는 인벤토리 클래스입니다. 

 

### 주요 기능 

- ItemSlot[]을 이용한 인벤토리 슬롯 관리

- Dictionary를 사용한 아이템별 슬롯 갯수 관리

- 아이템 추가 및 제거 

- 아이템 수량 및 소지 무게 관리 

- 재화 관리 

- 인벤토리 데이터 저장 및 불러오기 

- 인벤토리 정렬 

- Quick Slot과 Inventory Slot 연결

## Shop

상점의 슬롯을 관리하는 상점 클래스입니다. 

상점 슬롯 데이터를 불러옵니다.

## Storage

창고의 슬롯을 관리하는 창고 클래스입니다. 

 

### 주요 기능 

- 창고 슬롯 데이터 저장 및 불러오기 

- 슬롯 정렬 

- 인벤토리 슬롯과 상호작용
