## FieldOfView 

플레이어의 시야를 Mesh로 생성하고 적의 가시 상태를 관리하는 클래스입니다. 

플레이어 정면 부채꼴과 플레이어 주변 원형 시야 영역을 생성하며, Raycast를 이용해 장애물을 시야 Mesh에 반영합니다. 

HashSet<Enemy>로 현재와 이전 프레임의 시야 내 적을 관리하고, 적의 Render를 활성화 또는 비활성화합니다. 

 

### [시야 Mesh 생성] 

> 시야를 만들기 위해 시야각을 여러 개의 Ray로 나눠 검사합니다. 
>
> ViewCast()에서 각 Ray의 장애물 충돌 지점이나 최대 시야 거리의 지점 계산 후, 이를 BuildMesh()에 전달해서 시야 Mesh를 생성합니다. 
> 
> 인접한 Ray끼리 충돌 결과가 크게 달라지는 경우, FindEdge()를 통해 장애물 경계를 추가 탐색해 Mesh를 보정합니다. 

 

### [적 가시성 판별] 

> 부채꼴, 원형 시야를 각각 검사합니다. 
>
> OverlapSphere로 시야 반경 내 Enemy를 1차로 탐색한 후, 시야각과 장애물을 검사해 적이 플레이어의 시야에 들어왔는지 판단합니다.
