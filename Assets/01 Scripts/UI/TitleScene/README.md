# TitleScene

Title 씬에서만 사용되는 UI 클래스 폴더입니다.

## ✔ TitleButtonHoverArrow 

타이틀 화면에 지금 선택된 메뉴를 표시하기 위해 사용되는 HoverArrow를 관리합니다. 

ButtonHoverSound를 상속받아 메뉴에 마우스를 올렸을 때 효과음을 재생합니다.
