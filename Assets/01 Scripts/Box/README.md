Box
===

## ✔ Box
> 상자 클래스입니다.
> 
> 필드에 배치되는 다양한 상자(음식 상자, 약품 상자 등)가 하나의 추상 클래스 Box를 상속받도록 설계했습니다.
>  
> 상자별 아이템 등장 확률만 자식 클래스에서 정의하여 코드 중복 없이 다양한 상자를 구현할 수 있도록 구성했습니다. 

 
### [추상 클래스를 이용한 역할 분리] 

상자 종류마다 다른 아이템 타입 가중치만 설정합니다. 이로 인해 새로운 상자를 쉽게 추가할 수 있습니다. 

Start함수에서 SetWeightValue로 아이템 타입 가중치를 설정 후 가중치 테이블을 생성합니다. 

 

### [가중치 기반 아이템 생성] 

상자가 처음 열릴 때, 가중치 테이블을 기반으로 아이템이 정해집니다. 

상자 개봉-> 아이템 타입 결정 -> 랜덤 아이템 생성 

 

### [희귀도 연출] 

상자를 열면 아이템을 즉시 보여주지 않고 코루틴을 이용하여 아이템 로딩 연출을 적용했습니다. 

희귀도가 높은 아이템일수록 더 긴 연출 시간을 적용했습니다. 


## ✔ BoxSlotLoad

상자 아이템의 희귀도 연출을 위한 클래스입니다.
 
상자의 슬롯당 하나씩 할당됩니다. 



## ✔ LootBox

적을 쓰러뜨릴 경우 생성되는 전리품 상자입니다. Box.cs를 상속받습니다. 

슬롯별 정해진 아이템이 있기 때문에 Box.cs의 SetBoxItems을 오버라이드해 구현했습니다. 

- 1번째 슬롯: 적이 들고 있던 총 

- 2번째 슬롯: 총에 맞는 총알, 랜덤한 갯수 

- 3 ~ 5번째 슬롯: 약품, 음식, 잡동사니 중 랜덤 아이템 


## ✔ StarterBox

플레이어가 필드씬에 나오자마자 발견할 수 있는 보급 상자입니다. Box.cs를 상속받습니다. 

슬롯별 정해진 아이템이 있기 때문에 Box.cs의 SetBoxItems을 오버라이드해 구현했습니다. 

- 1번째 슬롯: 총(Glock) 

- 2번째 슬롯: 총에 맞는 총알, 30개 

- 3번째 슬롯: HP 회복 아이템
