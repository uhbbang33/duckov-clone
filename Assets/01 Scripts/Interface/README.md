# Interface

인터페이스를 모아둔 폴더입니다.

## ✔ ISaveableContainer 

아이템 슬롯의 저장 기능을 제공하는 클래스를 위한 인터페이스입니다. 

## ✔ ISortableContainer 

아이템 슬롯의 정렬 기능을 제공하는 클래스를 위한 인터페이스입니다. 

GetSortableSlots()를 통해 정렬 대상 슬롯을 반환하고,  

OnSortCompleted()를 통해 정렬 완료 후 필요한 처리를 구현할 수 있도록 구성했습니다.


## ✔ IUICloseable

UI를 닫는 기능을 제공하는 클래스를 위한 인터페이스입니다.
