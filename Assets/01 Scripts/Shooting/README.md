# Shooting



## ✔ Bullet 

총에서 나온 총알을 관리하는 클래스입니다. 

총의 총구 방향과 총의 사거리에 따라 발사됩니다. 

Object Pooling을 사용해 생성되고 반환됩니다. 

오브젝트에 충돌 시 Pool에 즉시 반환되고, 충돌하지 않았을 경우 총의 사거리에 도달했을 때 Pool에 반환됩니다. 

플레이어나 적 오브젝트에 충돌 시 오브젝트의 HealthPoint를 불러와 대미지를 주고 BloodSmoke 효과를 생성합니다.  그 외의 오브젝트에 충돌 시 Smoke 효과를 생성합니다. 

## ✔ Gun 

Pool에서 생성되는 총을 Hierarchy에서 자식으로 가져, 그 총의 Render를 관리합니다. 

총구의 위치를 관리합니다.
